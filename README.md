楼下小黑是一款 Windows 桌面工具箱，把日常文件处理、音视频、办公、电脑工具和可配置的 AI 助手集中在一个应用内。

## 基础功能

- 压缩与解压：常用压缩格式、批量处理和右键菜单入口。
- 音视频：播放、格式转换、裁剪，以及从视频中单独导出音频。
- 图片：预览、格式转换、压缩及合成拼接。
- 文件与办公：文档转换、PDF 处理、翻译和批量办公工具。
- 电脑工具：清理、硬件信息、故障检修，以及下载守卫内的正版软件官网入口。
- 小黑 AI：接入已配置的 AI 服务或本地模型；模型和账号不随安装包附送。

## 下载安装

打开 [最新版下载页](https://github.com/guoyi0759-source/louxiaxiaohei/releases/latest)，在 **Assets** 中下载 `LouXiaXiaoHei_Setup_版本_校验值.exe`，运行完整安装程序。

`update.json` 是自动更新清单，普通用户无需手动下载或打开。不要把 GitHub 自动生成的 `Source code (zip)` 或 `Source code (tar.gz)` 当作安装包。

完整安装包包含常用基础运行环境。部分功能仍有外部条件：AI 需要自行配置服务或模型；DWG 转 PDF 需要安装 AutoCAD 或免费的 Autodesk DWG TrueView，可从小黑的正版软件官网入口获取。

## 视频单独导出音频

进入 **音视频 → 批量转码**，导入视频，将输出格式设为 **MP3、WAV 或 M4A**，选择输出文件夹，然后点击 **开始批量转换**。

结果只含音频，不含视频画面，原视频保留不变。无音轨的视频不能导出音频。转成 WAV 或 FLAC 不会恢复原音轨已经损失的音质。

当前 Windows 3.80.32 安装版已通过三种格式的音轨、时长、原文件保留与界面按钮导出测试。

## 图片转文档

在 **转换** 页拖入或浏览导入图片，软件会自动识别源文件类别，只需选择目标 **PDF、TXT、Word（DOCX）或 Excel（XLSX）**。图片到图片的格式转换仍在图片页，不在这里重复列出。

多张图片可合并为一份 PDF（每图一页）或分别导出，保留源图片像素和方向；多帧图片目前取首帧。TXT、Word 和 Excel 使用内置离线 OCR，不需要手动安装识别模块。

Excel 按“识别后重建”生成可编辑的新表，重新安排标题、表头、行列、筛选和打印布局，不照搬图片装饰和巨大像素间距。工程目录图片的主表与页面信息分开，原图空白处不补造数据。窄字体和短数字会二次识别，有分歧的内容保留核对提示；主表相应单元格标黄并附批注。普通数值输出为可计算数字，前导零编号、长编号及公式样式文字保留为文本。复杂合并单元格、低清照片、专业符号和重要数字仍需人工复核。原图片保持不变，已有输出不会被覆盖。

## CAD 转换说明

PDF 转 DWG 位于转换页，支持矢量重建、选页、比例及复杂图纸按整页分批。它不是专业 CAD 的无损替代：扫描 PDF 不能直接恢复为可编辑图纸；已转曲文字保留轮廓，原始图层、块及关联标注不能完整还原。重要工程成果请人工复核。

DWG 转 PDF 使用另外安装的 CAD/查看器输出，缺失字体可能影响结果，转换前应检查。

## 更新与安全

公司电脑优先尝试内网更新，内网不可用时尝试 GitHub。旧版首次接入更新可能需要覆盖安装一次。GitHub 的访问速度和可用性取决于所在网络。

小黑不是 Microsoft Defender 的替代品，不应为了安装而关闭安全保护。
